# Снимки текущей версии

78 PNG: 33 ролевых экрана и 6 основных открытых окон, каждый в двух размерах: desktop 1440 × 1000 и mobile 390 × 844. Это первый видимый экран, не полная прокрутка страницы. Снимки получены из работающего прототипа в браузере; интерфейс и адаптивность не исправлялись.

Использованы встроенные вымышленные демо-данные в отдельном origin localhost. Реальные хранилища пользователя не экспортировались. Значения отражают момент съёмки. Метаданные: ../screen-evidence.json и ../aux-evidence.json. Ссылки и пути открытия: ../screens.md и ../dialogs.md.

Для перехода по прямому адресу следует полностью открыть URL: простая замена hash у уже открытого прототипа не всегда перерисовывает экран.
