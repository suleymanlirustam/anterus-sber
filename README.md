# Антерус — материалы для команды проекта

Клиника «Антерус» (Москва) — психиатрия и психотерапия. Здесь — то, что нужно команде для работы над
расписанием, оформлением пациентов, печатью документов и ИИ-агентом «расшифровка приёма → черновик
медкарты». Задание (ТЗ) и шаблоны медкарт клиника передаёт отдельно.

## Правила

- **Только выдуманные данные.** Все люди, записи, суммы и документы здесь вымышлены. Настоящих данных
  пациентов в репозитории нет и быть не должно — ни в коде, ни в тестах, ни в снимках экранов, ни в
  записях приёмов.
- **Без ключей и паролей.** Доступа к серверу клиники и к МИС (SQNS) у команды нет и не нужно. Всё, что
  приходит «с сервера», отдаёт заглушка из `web/mock/`.
- **Автотесты на GitHub (Actions) в этом репозитории выключены.** Проверки запускаются у себя: `npm test`.

## Что здесь

| Папка | Что |
|---|---|
| `web/` | Наша панель в минимальном виде: общая оболочка окон сотрудников и **окно врача** — сюда встраивается ИИ-агент. Запускается без сервера, на заглушке. |
| `web/mock/` | Заглушка сервера: отвечает на `/api/...` выдуманными данными. Новые адреса добавляются в `mock/plugin.ts`. |
| `contracts/` | Описание обмена данными с нашей системой: что модули спрашивают и что отдают. **Черновик** — уточняется вместе. |
| `templates/` | Заглушки документов (договор, ИДС, согласия) с полями и состав пакетов документов. |
| `design/` | Дизайн CRM: токены оформления, компоненты, снимки экранов прототипа (данные на снимках демонстрационные). |

## Запуск окна врача

Нужен Node.js 22+.

```powershell
cd web
npm ci
npm run dev
```

Открыть http://localhost:5173 — окно врача на выдуманных данных.

Проверки, как у нас перед каждой выкладкой:

```powershell
npx tsc -b
npx eslint .
npx playwright install chromium
npm test
```

## Стек

Интерфейс — React 19, TypeScript, Vite, Tailwind CSS 4, shadcn/ui (Radix), TanStack Query; тесты —
vitest в браузере. Сервер клиники — Python 3.13, PostgreSQL. Если для вашей части удобнее другое —
предложите, обсудим до начала.
