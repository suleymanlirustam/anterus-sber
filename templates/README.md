# Документы: пакеты и заглушки шаблонов

Тексты здесь — **заглушки**. Настоящие тексты договора, ИДС и согласий клиника вставит сама в редактор
шаблонов, который делает команда. Задача модуля — механизм: шаблон с полями → документ с данными
пациента → печать; пакет документов собирается по признакам визита.

## Пакеты

| Пакет | Состав |
|---|---|
| Взрослый, в клинике | договор, ИДС, согласие на обработку ПДн (в т.ч. ЕГИСЗ) |
| Несовершеннолетний, в клинике | то же + данные представителя и документ о полномочиях |
| Взрослый, онлайн | пакет взрослого + согласие на телемедицину |
| Несовершеннолетний, онлайн | пакет несовершеннолетнего + согласие на телемедицину |

- Взрослый — с 18 лет на дату визита, несовершеннолетний — до 18. Детский пакет один на всех до 18 лет.
- Онлайн или в клинике — признак визита, его отдаёт наша система (`format` в `contracts/`).
- Система предлагает пакет сама; администратор всегда может выбрать другой вручную.
- Состав пакетов редактируется: добавить, убрать, заменить шаблон, завести новый пакет.
- Правят шаблоны и пакеты Владелец и Управляющая; остальные — только печатают.
- Кто и когда поменял шаблон — видно в журнале.
- Напечатанный документ остаётся таким, каким его напечатали, даже если шаблон потом изменили —
  версии шаблонов хранятся.

## Стороны в документах

У несовершеннолетнего в документах две стороны: **Пациент** и **Заказчик** (законный представитель, он же
плательщик). У каждой свои поля. Договор и оплата — только Заказчик. С 15 лет часть документов
(ИДС, согласие на телемедицину) подписывает сам пациент — это решается текстом шаблона, не системой.

## Поля

| Поле | Что |
|---|---|
| `{{patient.last_name}}`, `{{patient.first_name}}`, `{{patient.middle_name}}` | ФИО пациента |
| `{{patient.birth_date}}` | дата рождения |
| `{{patient.phone}}`, `{{patient.email}}` | контакты |
| `{{patient.passport.series}}`, `.number`, `.issued_by`, `.issued_at`, `.division_code` | паспорт |
| `{{patient.address}}` | адрес регистрации |
| `{{customer.*}}` | те же поля для Заказчика (представителя) |
| `{{authority.type}}` | документ о полномочиях: свидетельство о рождении, решение органа опеки или решение суда |
| `{{authority.number}}`, `{{authority.date}}`, `{{authority.issued_by}}` | его реквизиты |
| `{{visit.date}}`, `{{visit.time}}`, `{{visit.doctor}}`, `{{visit.services}}`, `{{visit.price}}` | приём |
| `{{clinic.name}}`, `{{clinic.address}}`, `{{clinic.license}}` | реквизиты клиники |
| `{{today}}` | дата печати |

Данные пациента приходят не только с ручного ввода: форма оформления принимает их готовыми из другого
источника (например, из сервиса, где пациент сам вносит паспорт с телефона) — администратор видит их и
подтверждает.

Файлы `*.md` рядом — заглушки шаблонов: вымышленный текст + поля.
